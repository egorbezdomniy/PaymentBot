# PaymentBot

Бот получает уведомление о покупке, регистрирует подписку в отдельном API и отправляет покупателю письмо.

Скопируйте `.env.example` в `.env`, заполните параметры Telegram, SMTP и API подписок. В `PAYMENT_SOURCE_USER_ID` укажите Telegram ID отправителя уведомлений о покупке. Установите зависимости командой `python -m pip install -r requirements.txt`. Бот запускается командой `python main.py`.

При локальной проверке подменяйте отправку почты, Telegram и запросы к API подписок.
